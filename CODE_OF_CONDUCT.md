# Code of Conduct

This project welcomes careful scholarly and technical disagreement.

Participants are expected to:

- discuss evidence and implementation choices rather than attack people;
- distinguish documented source evidence from interpretation;
- state uncertainty where evidence is ambiguous;
- avoid sectarian, ethnic, religious, or personal harassment;
- avoid knowingly falsifying citations, source references, or test results;
- give maintainers and contributors room to correct mistakes.

Maintainers may close discussions or reject contributions that are abusive, deceptive, persistently disruptive, or unrelated to improving the project.
