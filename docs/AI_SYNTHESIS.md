# AI synthesis disclosure

The dictionary was not generated by asking a model for unconstrained root meanings.

For each root, deterministic code assembled a structured evidence packet from Quranic morphology and lexical sources. An LLM then synthesized that supplied evidence into the public dictionary schema.

## Model role

The model's role was:

- organize evidence;
- formulate concise definitions;
- distinguish Quran-attested form senses from broader Classical meanings;
- preserve cautions/ambiguity;
- attach only supplied source references;
- account for every QAC form group and every supplied Lane evidence unit.

The model was **not** treated as a lexical authority.

## Production synthesis

The frozen production workflow used:

```text
synthesize_root_dictionary_v11.py
model family documented by the research project: gpt-5.6-luna
reasoning: high
max output tokens after truncation fix: 80,000
automatic retry: none
```

The exact production history, including Batch accounting and later deterministic repair, is documented in the preserved research records.

## Validation

Generated artifacts were passed through deterministic validators. Hard integrity failures were not considered ready for semantic freeze.

Warnings could remain where they did not violate the user-visible lexical integrity contract.

## Re-running

A new synthesis run should be treated as a new generated version. Do not silently overwrite the frozen corpus.
